Also decided:
- Landing format: raw API pages as gzipped JSON into one `VARIANT` column plus load metadata, flattened in dbt staging.
- The README lists the prerequisites (DOL API key, Snowflake account). `uv run pytest` runs with no accounts, on synthetic fixtures.
- `aws/aws-emulator` was evaluated and not adopted for v1. The AWS work in M3 is the S3 → Snowflake storage integration and the GitHub OIDC trust; Snowflake cannot read from an emulator on `127.0.0.1`, and the emulator's README says not to use it to test security. Reconsider at M3 only if a CI test of the S3 upload against the real bucket proves awkward. Its S3 fidelity score was not checked.

Facts checked 2026-11-12:
- Snowflake Standard on AWS us-east-1 is $2.00 per credit, so a cap of at most $5/month is a 2-credit monthly quota (2 hours of an XS warehouse). The trial is 30 days or $400, whichever ends first.
- Tableau Public auto-sync ("Keep this data in sync") requires Tableau Desktop Public Edition.

Ingest constraints from the data spike (E1): the key is accepted only as the `X-API-KEY` query parameter, the API returns 429 after about 13 back-to-back pages with no rate headers, `load_dt` is the incremental watermark, and NAICS codes are dirty.

## Steps

### 1. Owner actions
- 2026-11-13: create the Snowflake trial (Standard, AWS us-east-1, MFA on the login).
- Any day: the Tableau test. Make a Google Sheet with columns `industry, state, year, cases`, build one bar chart in Tableau Desktop Public Edition, publish with "Keep this data in sync" on and downloads off.

### 2. Snowflake bootstrap (owner present for credentials)
- Look up current syntax first: resource monitors, key-pair auth for dbt-snowflake.
- Commit `infra/snowflake/bootstrap.sql`, with no secrets in it: a resource monitor with a 2-credit monthly quota, notify at 75%, `SUSPEND` at 100%; an XS warehouse with `AUTO_SUSPEND=60` and a statement timeout; one database with `raw` / `staging` / `marts` schemas; a loader/transformer role; a service user with key-pair auth.
- Generate the key pair locally. The private key goes to the secrets manager over stdin at a hidden prompt, followed by a sha256 compare. It is never printed.

### 3. Ingest client (test-first)
- `uv run pipeline ingest`: httpx, `httpx` loggers at WARNING, the key redacted from exception text, a sleep between pages, exponential backoff on 429, a checkpointed offset so a backfill resumes, the `load_dt` watermark after the first backfill.
- Writes gzipped JSON pages locally, then `PUT` to the internal stage and `COPY INTO raw.whd_enforcement`.
- Dependencies, each pinned to a version at least two weeks old and checked at write time: `httpx`, `snowflake-connector-python`, `dbt-snowflake`, `pytest`, `ruff`.
- Tests use synthetic fixtures only: backoff, resume, redaction.

### 4. dbt models
- `stg_whd__cases` (flatten the VARIANT) and `stg_whd__case_acts` (unpivot the per-act columns; names from `docs/reference/whd_enforcement_metadata.json`).
- `dim_industry` (NAICS cleaning, an accepted-values test, the unmapped share measured and stated), `dim_state`, `dim_date`, `fct_compliance_actions` at case × act grain.
- `agg_industry_state_year`: the aggregate behind the chart. It becomes `public_export` in M4.
- Tests and docs on every model.

### 5. Chart, docs, ship
- Paste `agg_industry_state_year` into the Tableau test Sheet, confirm the viz updates within 24 hours, and link it in the README.
- ADRs 0001–0003: the warehouse choice, the aggregates-only export, the thin orchestrator.
- README: problem, architecture, cost model (credits used by one full `dbt build`), status line.
- One PR, then a retro in this directory.

## Verification
- `uv run pytest` is green with no credentials in the environment.
- `uv run pipeline ingest && dbt build` is green, and the raw row count matches the paged count from the API.
- Redaction guard: break the redaction once, confirm the test fails, restore it, clear `__pycache__`.
- Cost guard: set the monitor quota to its minimum, confirm the warehouse suspends and the next `dbt build` fails, then restore the quota.
- gitleaks is clean before every push.
- The Tableau viz shows the real aggregates the day after the paste.
